# ResearcherOS StarterKIT

Первое исследование с AI-агентом на рекламных данных: подключите проект, создайте дерево, проведите эксперимент и попробуйте улучшить результат через Arbor.

**Задача:** предсказать числовую взвешенную долю кликов (wCTR) по описанию объявления, дате и аудитории. Одна строка - ячейка рекламного отчёта, а не отдельный человек. Данные взяты из [Sell me this!](https://github.com/ZoyaV/sell-me-this).

[Начать с шага 1](walkthrough/01-install.md)

## Как пользоваться

1. Клонируйте этот репозиторий и установите ResearcherOS по первому шагу.
2. Читайте файлы `walkthrough` по порядку. В каждом есть действия в интерфейсе, сообщение для копирования и проверка результата.
3. Сообщения агенту вставляйте в чат ResearcherOS. Команды `git`, `python` и `pip` выполняйте в терминале. Команды со слешем, например `/run`, выполняйте в чате карточки.

## Что внутри

- `data/` - таблица, описание происхождения и фиксированное разделение на выборки.
- `walkthrough/` - пять заданий с готовыми сообщениями агенту.
- `scripts/` - проверка данных и сборка руководства.
- `AGENTS.md` - границы учебного исследования для агента.

В исходном StarterKIT только ветка `main`. Дерево не подготовлено заранее: вы создадите его в ResearcherOS. Приложение само управляет отдельным хранением исследовательских материалов; служебная ветка дерева в вашем рабочем окружении не является дополнительной веткой этого шаблона.

## Локальная проверка

Для проверки данных достаточно Python 3.10 или новее, без дополнительных пакетов:

```bash
python scripts/check_data.py
```

Для экспериментов используйте отдельное окружение:

```bash
python -m venv .venv
```

Активация на macOS / Linux: `source .venv/bin/activate`. На Windows PowerShell: `.venv\Scripts\Activate.ps1`. Затем:

```bash
python -m pip install -r requirements.txt
```

Сам код первого эксперимента агент создаст при выполнении карточки. Результатов и готовых исследовательских выводов в шаблоне нет.

Полное описание данных и правил оценки: [data/README.md](data/README.md).

# 6. Сокращение отчёта и словарь

## Что попробуем

Сделаем отчёт удобнее для чтения и зададим предпочтительные термины для своего дерева.

## Действия

1. Откройте завершённую карточку и её чат. Можно продолжить прежний разговор или через список чатов нажать «Новый чат карточки». Проверьте, что новый разговор связан с той же карточкой.
2. Отправьте первый блок с `/compress`. Эта команда вызывает скилл `koi-reader-rewrite`: он проверяет читаемость и при необходимости переписывает текст. Уже понятный отчёт может остаться без изменений.
3. Прочитайте сокращённую версию. Проверьте сохранность метрик, ограничений, правила вывода, таблиц и изображений.
4. Откройте «Словарь» в канбане метода. Добавьте правило `бейзлайн > исходное решение` и сохраните. Здесь правило действует для выбранного дерева. Не используйте «Словарь для всех деревьев», если не хотите менять терминологию других проектов.
5. После сохранения словаря отправьте второй блок в чат той же карточки. Вместо примера можно добавить свой термин в формате `термин > замена`.

## Сообщение для сокращения

```text
/compress Сделай отчёт этой карточки понятным исследователю,
который не видел наш запуск. Сохрани числа, критерий 1%,
таблицы, изображения, ограничения, ссылки и воспроизводимость.
Не меняй смысл отрицательного результата и не усиливай вывод.
Если текст уже читается хорошо, объясни, почему правка не нужна.
```

## Сообщение после изменения словаря

```text
Прочитай сохранённый словарь этого дерева заново.
Перепиши только прозу отчёта текущей карточки с учётом правила
«бейзлайн > исходное решение». Не меняй числа, код, имена файлов,
цитаты, идентификаторы, правило решения и статус карточки.
Если слово не встречается, не добавляй его искусственно.
Покажи, какие фрагменты изменились. Другие отчёты не редактируй.
```

## Проверка результата

Отчёт сохранил факты и изображения. Замены применены к прозе текущего отчёта. Словарь сам по себе не переписал старые отчёты и не изменил другие деревья.

# Маршрут знакомства

Откройте [шаг 1](01-install.md), затем двигайтесь по номерам до [шага 8](08-arbor-tree.md). Сообщения из блоков «для копирования» отправляйте в указанный чат ResearcherOS. Терминальные команды выполняйте отдельно, в локальной папке проекта.

После каждого шага проверьте результат в конце файла. Если он не получен, сначала закончите текущий шаг. Одновременный запуск нескольких копий одного опыта не ускоряет знакомство и смешивает результаты.

Те же восемь шагов собраны в [PDF](../guide/starter-kit.pdf).

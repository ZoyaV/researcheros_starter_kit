# Маршрут знакомства

Откройте [шаг 1](01-install.md), затем переходите к следующим разделам по [оглавлению](../README.md). Сообщения из блоков «для копирования» отправляйте в указанный чат ResearcherOS. Терминальные команды выполняйте отдельно, в локальной папке проекта.

После каждого шага проверьте результат в конце файла. Если он не получен, сначала закончите текущий шаг. Одновременный запуск нескольких копий одного опыта не ускоряет знакомство и смешивает результаты.
